# Two-dimensional relative-tolerance benchmark

These directories contain the retained outputs for the 1--87 mH coil lattice
with a relative target tolerance. See `../../essay/evidence_manifest.md` for
the exact claim-to-script-to-data mapping and `../README.md` for the grouped
directory index.

Folder names describe the experiment rather than serving as another protocol
version number. This prevents the former outer `01_` label and inner numbered
stages from being mistaken for missing result families.
